## 🚀 How to Run

### Console Applications (PB)

**Prerequisites:**
- .NET Framework 4.5+
- Visual Studio (2019 or later) OR Visual Studio Code with C# extension

**Steps:**
1. Open `PB.sln` in Visual Studio
2. Right-click on desired program (e.g., `BMI.cs`) → Set as Startup Item
3. Build → Rebuild Solution (Ctrl + Shift + B)
4. Run the program (F5 or Ctrl + F5)
5. Follow console prompts for input

Alternatively, build to an `.exe` and run from Command Prompt.

### ASP.NET Web Applications (TempConfig)

**Prerequisites:**
- .NET Framework 4.5+
- Visual Studio (2019 or later)
- IIS Express (bundled with Visual Studio)

**Steps:**
1. Open `TempConfig.sln` in Visual Studio
2. Select desired project (e.g., `Temp1`)
3. Right-click → Set as Startup Project
4. Press F5 to run with IIS Express
5. Application opens in browser at `http://localhost:PORT/`
6. Browse through pages: Home, Properties, Contact, etc.

**Alternative (Local IIS):**
- Right-click project → Properties → Web
- Select "Local IIS" option
- Configure Virtual Directory
- Press F5 to launch
